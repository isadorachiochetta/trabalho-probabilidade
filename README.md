# Trabalho 1 — Probabilidade e Estatística

Este projeto foi feito para resolver os 19 exercícios da lista usando HTML, CSS e JavaScript.

## Como abrir

1. Extraia os arquivos da pasta.
2. Abra o arquivo `index.html` em um navegador, como Chrome, Edge ou Firefox.
3. Escolha o exercício no menu, confira os valores e clique em **Calcular**.

## Arquivos

- `index.html`: estrutura da página.
- `style.css`: cores, organização e aparência da página.
- `script.js`: campos e cálculos dos exercícios.

## Observações

- Os valores que aparecem nos campos são exemplos e podem ser alterados.
- Nos campos de probabilidade, informe valores entre 0 e 1. Nos campos que pedem porcentagem, informe valores como `10` para representar 10%.
- No exercício 1, informe os elementos dos conjuntos separados por vírgulas.
- Nos exercícios 7 e 8, informe os nomes e os percentuais na mesma ordem, separados por vírgulas.
- O cálculo do exercício 9 considera os componentes independentes.
- Para a distribuição normal, usamos uma aproximação numérica, então pode haver pequenas diferenças de arredondamento.
